# Проверки этапа 6

Запустить оптимизированную preview-сборку:

```powershell
npm.cmd run build
npm.cmd run start -- --hostname 127.0.0.1
```

В другом терминале `npm.cmd run test:routes` проверяет пять HTTP-маршрутов, статусы, noindex, один H1, metadata и отсутствие утечек черновиков. Это HTTP-проверка, не браузерный Playwright suite.

Браузерный сценарий через CUA:

1. Просмотреть `/about` и `/topics` на 1440/1024/768/390/320 px; проверять фактический `innerWidth`, отсутствие overflow, читаемость и crop.
2. На 390 открыть меню, выбрать «Темы», проверить URL, закрытие dialog и восстановление прокрутки. Проверить Enter на «На главную» и правильный текущий пункт меню.
3. Для disclosure отдельно запустить `node tests/e2e/disclosure-server.mjs`, открыть `http://127.0.0.1:3002/`. Стенд использует настоящий Accordion с тестовыми ответами, CSP запрещает скрипты. Проверить Enter/Space на `summary`, длинный ответ на 320 px и visible focus. Остановить стенд после проверки.

Fixtures не входят в Next routes и не описывают услуги Анны. Публичные `/faq` и `/sessions` остаются недоступными, пока нет подтверждённого содержания. Результаты фактически выполненных проверок: [этап 6](../../docs/design/interior/README.md).
